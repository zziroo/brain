- **Coordination:** [[orchestrator-mode]]. Agent changes (edited in place, uncommitted; worktree + branch only for overlapping parallel work) → review agent on the diff → sonnet skeptic for medium+ → fixes → coordinator runs `pnpm -r typecheck` + `pnpm -r test` → commit → push. If a branch/worktree was used: `git merge --no-ff` first, then remove the worktree with `cmd /c "rmdir /s /q \\?\<literal path>"` (no `$var`; retry once if "in use") + `git worktree prune` + `git branch -d`. Merged branches are deleted on GitHub too (user agreed 2026-09-30); never delete an unmerged branch without asking.
- **Deploy (server):** on the VPS ([[diskort-server]]): backup (`bash infra/backup-db.sh`) if schema changes → `git pull --ff-only` → `docker compose up -d --no-deps --build api` → check `PRAGMA user_version`/integrity via `docker compose exec -T api node -e …` + error count in logs. `apps/web` needs only git pull. `infra/caddy/diskort.caddy` changes: `git pull`, then `bash /opt/ziroo-edge/reload.sh`. Never run `docker compose ... caddy` on prod.
- **Release:** bump `apps/desktop` AND `apps/mobile` package.json (versions must match) → commit "Sürüm X" → `git tag vX && git push origin vX` → `.github/workflows/release.yml` builds Win/Linux/mac into a draft (mac: Developer ID signed + notarized since 0.10.3, ~35 min) → `gh run watch <id>` in background → check assets (exe/dmg/AppImage/deb; apk+ipa reused when fingerprint unchanged; `ota-*.json` runtimeVersion) → `gh release edit vX --draft=false --latest --notes-file` (Turkish notes in scratchpad) → poll `https://diskort.ziroo.net/updates/latest.yml`. Publishing = mandatory update (server rejects older gateway clients within 5 min). Deploy the server before publishing a client that needs it. GitHub push sometimes fails to connect — retry. More: vault `runbooks\surum-cikarma.md`, `runbooks\deploy.md`.
- **Admin panel:** https://diskort.ziroo.net/admin (feedback, security, voice quality, infra, API health, iPhone devices, connection diagnosis). Logs in the api container: `/data/client-errors.jsonl`, `/data/server-errors.jsonl`, `/data/telemetry/*.jsonl`, auth-log.jsonl. Read via `ssh -i ~/.ssh/diskort_vps root@<VPS_IP> 'cd /opt/diskort/infra && docker compose exec -T api …'`; no scp — download with `ssh … cat file > local`. Grouped error summary: `ssh … "cd /opt/diskort/infra && docker compose exec -T api node - <sinceMs>" < /Users/ziroo/diskort-inbox/hata-ozet.js`.
- **Routines + inbox:** only the watcher remains: "diskort feedback rutin" (`diskort-geri-bildirim-kontrolu`, daily 00:10: feedback + errors → inbox, one push only if it wrote something). Nightly code review routine deleted 2026-10-10 (user wants a shared review mechanism across projects later). Task `cwd` must exist (`/Users/ziroo/ZZ/zProjects/diskort`), else runs silently open no session; only the user can change it in the app. Inbox `/Users/ziroo/diskort-inbox/` (outside `.claude` on purpose: writes under `.claude` always prompt and stall unattended runs; review marker `/Users/ziroo/diskort-review/last-reviewed.txt`); files `YYYY-MM-DD-HHmm-<tür>.md`, `durum.json`, `hata-ozet.js`. The coordinator reads unread files at session start, then moves them to `okundu/`. Routines must write files with Write/Edit (Bash heredoc triggers prompts). They are LOCAL desktop scheduled tasks; prompts are `/Users/ziroo/.claude/scheduled-tasks/<name>/SKILL.md`; inspect runs with scheduled-tasks list_task_runs.
- **Local UI test env:** local server from the working copy on a free port + temp DATA_DIR; desktop dev with `VITE_DEFAULT_SERVER`, `DISKORT_PROFILE`, `DISKORT_DEBUG_PORT`, CDP; local LiveKit in `tools/livekit`. Clean up processes and `%APPDATA%\Diskort-dev-<name>`.
- **Phone access:** Claude Code CLI (Mac: `~/.local/bin/claude`; was `claude.exe` on Windows until 2026-10-05). User runs `claude rc` in a separate Terminal window in the diskort folder; the phone's Code → Devices shows the PC. Don't run two coordinator sessions on main at once.
- **Style:** Turkish replies, short status. No `python` in bash. Don't prettier existing files. Use Write/Edit for code with backslashes.
