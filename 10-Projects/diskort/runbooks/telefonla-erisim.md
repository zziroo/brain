# Telefondan PC'deki Claude oturumuna erişim: `claude rc`

Claude Code CLI `C:\Users\yusuf\.local\bin\claude.exe` (PATH'e Yusuf kendi ekler). Yusuf ayrı bir Windows Terminal'de diskort klasöründe `claude rc` çalıştırır (spawn modu same-dir); telefonda Code -> Devices PC'yi gösterir ve orada yeni oturum başlatabilir. Aynı anda main üzerinde iki koordinatör oturumu çalıştırma.
