# Production sunucu: LightNode İstanbul VPS, SSH yalnız anahtarla, docker compose ile livekit + api; 80/443 ayrı ziroo-edge projesinde

Gizli değerler yazılmaz; yalnız konumlar.

- **VPS (2026-10-01'den beri):** LightNode "Istanbul II" (KVM, CPU Shared 2 vCPU, 4 GB, 50 GB, Ubuntu 24.04), IP `38.60.208.88`, saatlik faturalı (~14 $/ay), trafik paketi 1000 GB (kullanım ~800 GB/ay). İki ağ kartı: eth1 genel, eth0 özel. Neden taşındı: [[sunucu-lightnode-istanbula-tasindi]]. Eski: isimkayit "IK Cloud 4 TR", 185.92.0.242 (kapsayıcılar durduruldu, silinecek).
- **SSH:** `ssh -i ~/.ssh/diskort_vps root@38.60.208.88`. Yalnız anahtarla (`/etc/ssh/sshd_config.d/00-diskort-hardening.conf`). İki anahtar yetkili: `diskort_vps` (ed25519, tüm araçlar bunu kullanır) ve `diskort_lightnode` (RSA; LightNode paneli yalnız RSA kabul ediyor). Kurtarma: LightNode panel konsolu.
- **Yığın:** repo `/opt/diskort`, compose `/opt/diskort/infra` (livekit, api; caddy servisi profilde, üretimde kapalı; host network; ufw açık: 22, 80, 443, 7881/tcp, 3478/udp, 50000-60000/udp). Secret'lar `/opt/diskort/infra/.env` içinde (yazdırma).
- **Alan adları** (Cloudflare, ziroo.net, yalnız DNS / gri bulut): `diskort.ziroo.net` -> API/gateway/indirme sayfası, `lk.ziroo.net` -> LiveKit, `turn.ziroo.net` -> TURN/TLS. Let's Encrypt, Caddy ile. **2026-10-03'ten beri joker kayıt:** `*.ziroo.net` A → sunucu IP'si (gri bulut); ayrı `diskort`, `lk`, `turn`, `kapis` kayıtları silindi, hepsi jokerle çözülüyor. Joker silinirse Diskort (ses dahil) ve KAPIŞ da düşer. Yeni alt alan adı için DNS gerekmez ([[2026-10-03-joker-dns-ve-tools-games-alt-alan-adlari]]).
- **İndirme sayfası:** `apps/web` (statik) Caddy'den https://diskort.ziroo.net (+ /download). `/download/<platform>` API'den son GitHub release varlığına 302; kullanıcı GitHub'ı görmez. Caddy /api/*, /gateway, /download/* yollarını API'ye yollar.
- **ziroo-www, tools ve games (2026-10-03'ten beri):** statik kökler `/opt/ziroo-www/{tools,games,home}` (home = `ziroo.net` ana sayfası, 2026-10-05'ten beri; edge'de `/srv/www:ro`). Hub site blokları ziroo-edge deposunda `config/hubs/{tools,games}.caddy`, ortak snippet `config/snippets/ziroo-static.caddy`. Proje-özel yollar `/opt/ziroo-sites/tools/<ad>.caddy` ve `/opt/ziroo-sites/games/<ad>.caddy` (kurulu: `steam-avgr.caddy`, `ziroobank.caddy`). Eski adresler 301: `/opt/ziroo-sites/tasinan-adresler.caddy` (kaynak `config/diskort-yollari/tasinan-adresler.caddy`). Araç ve oyun listeleri ziroo-edge `www/{tools,games}/` (ortak tasarım `www/shared/hub.css`) → `bash deploy-www.sh [tools|games|all]` (2026-10-05'ten beri; [[2026-10-05-liste-sayfalari-ziroo-edge-te-ortak-neon-tasarim]]). Doğrulama: `bash /opt/ziroo-edge/test/smoke.sh live`; geçiş runbook'u `docs/gecis-tools-games-alt-alan-adlari.md` (ziroo-edge). **Eski kopyalar** `/opt/diskort/apps/web/tools`, `/games`, `games.html` hâlâ duruyor; temizlik (runbook Faz D) birkaç gün sonra, açık iş. Eski `/opt/ziroo-sites/steam.caddy` ve `ziroobank.caddy` kaldırıldı (yedek `/root/gecis-2026-10/`). Karar: [[2026-10-03-joker-dns-ve-tools-games-alt-alan-adlari]]; eski: [[2026-10-02-oyunlar-diskort-alan-adinda-games-altinda]].
- **Araçlar:** Çeviri Aracı artık https://tools.ziroo.net/ceviri-araci (eski `/opt/diskort/apps/web/tools/ceviri-araci/` kopyası temizlik bekliyor, yukarıya bak). Betik `string-tool/deploy/deploy.sh`; hedefinin yeni köke uyumu doğrulanmadı. Ayrıntı: [[10-Projects/ceviri-araci/_overview|Çeviri Aracı]].
- **Giriş kapısı (2026-10-03'ten beri):** Caddy ayrı `ziroo-edge` projesi (`/opt/ziroo-edge`, kapsayıcı `ziroo-edge`, GitHub `zziroo/ziroo-edge`). Diskort siteleri `/opt/diskort/infra/caddy/diskort.caddy`'den, diğer projeler `/opt/ziroo-sites/*.caddy` (Diskort alan adında yol) ve `/opt/ziroo-sites/hosts/*.caddy` (kendi alan adı) üzerinden. Her değişiklik `bash /opt/ziroo-edge/reload.sh`. Diskort compose'unda `caddy` asla başlatılmaz (SO_REUSEPORT, 443 sessizce paylaşılır). [[2026-10-03-caddy-ziroo-edge-projesine-ayrildi]]

- **Makine izleme (2026-10-16, ops):** https://ops.ziroo.net → Uptime Kuma (konteyner `kuma`, 127.0.0.1:3001, veri `/opt/ziroo-ops/kuma`, kendi girişi, Telegram bildirimi); https://ops.ziroo.net/netdata/ → Netdata (konteyner `netdata`, host ağı 127.0.0.1:19999, basic auth kullanıcı `ziroo`, şifre `/opt/ziroo-ops/netdata.pass`). Kaynak ziroo-edge `ops/` (`/opt/ziroo-edge/ops`), host bloğu `/opt/ziroo-sites/hosts/ops.caddy`; güncelleme yerelden `bash ops/deploy.sh`, kontrol `bash /opt/ziroo-edge/test/smoke.sh live ops`. Saatlik `ziroo-ops-check.timer` → `ops/check.sh` (yedek yaşı, disk, smoke → Kuma push; jetonlar `/opt/ziroo-ops/check.env`). - **TURN/TLS 443:** özel Caddy imajı (`infra/caddy/Dockerfile`, caddy-l4) SNI `turn.ziroo.net` -> TLS sonlandırma -> PROXY v2 -> LiveKit 127.0.0.1:5349. 2026-09-26'da uçtan uca doğrulandı (röle ~23 ms vs doğrudan ~21 ms). LiveKit 1.13 fiilen `turns:turn.ziroo.net:443` ilan ediyor; masaüstü `turnPort.ts` yeniden yazımı sigorta olarak duruyor.
- **Bakım:** yeni sunucuda unattended-upgrades LightNode görüntüsünde maskeli, otomatik güvenlik güncellemesi ÇALIŞMIYOR (ayar dosyası `52diskort-auto-reboot` yazıldı, hizmet açılmadı). Açık iş; plan [[2026-10-15-sunucu-bakim-penceresi-07-30]]. Sunucu saat dilimi İstanbul. **Sakin saat:** 07:00–09:00 İstanbul (14 günde hiç oturum yok); ölçmek için api kabında `voice_sessions` tablosundan (`started_at`/`last_seen_at`) saatlik doluluk histogramı çıkar; `livekit_participant_total` metriği anlık doluluğu verir.
- **UDP (yeni sunucu, 2026-10-01):** 10.000 paket/sn'ye kadar gelen UDP kayıpsız, gecikme ~19 ms. Eski sunucuda: 2026-09-26'da 6 Mbps yayın, %0 kayıp, ~22 ms RTT doğrulandı. UDP tamponları `/etc/sysctl.d/60-diskort-udp.conf` (rmem/wmem_max 5000000). Ölçüm: 2 kullanıcı + bir yayın ~8.7 Mbps her yön, livekit tek çekirdeğin ~%22'si.
- **DB yolu** api konteynerinde `/data/diskort.db` (`docker compose exec -T api node -e ...` + node:sqlite). Mevcut DB şema numarası [[_overview]] "Güncel durum"da.
