# Karar: Altı kozmetik set herkese ücretsizdir

## Bağlam
Vitrin sayfası gösterildikten sonra setlerin (profil efekti + avatar süsü + isim plakası) nasıl sunulacağı soruldu.

## Karar
Altı setin hepsi tüm kullanıcılara ücretsiz; satın alma ya da yönetici verme yok. Animasyonlar uygulama içinde kodla çizilir (o dönem), sunucuda resim olarak durmaz.

## Neden
Kullanıcı açıkça istedi ("bu setlerin hepsini herkese ücretsiz sunalım"). 30 Eylül'de "ücretsiz mağaza" mantığıyla çelişmediği teyit edildi: [[kozmetik-paketleri-sunucudan-on-render]].

## Reddedilen alternatifler
- Set başına ücretli/kilitli model: kullanıcı istemedi (oturumda ayrı alternatif tartışması yok; gerekçe kullanıcı talimatı).
