# DM'ler sunucu bilgisi göstermez; profil ayarları hesap düzeyindedir

## Karar
- DM'de roller, rol renkleri, kick/ban gibi sunucu bilgisi gösterilmez.
- Profil ayarları hesap düzeyindedir (sunucu bazlı değil).
- Geri bildirim bağlamı DM adı/kimliği içermez.

## Neden
Kaynakta açık gerekçe yok; DM'in sunucudan bağımsız, özel bir alan olması ilkesi (yorum).

## Reddedilen alternatifler
Sunucu bazlı profil ve DM'de rol gösterimi (ima edilen; kaynakta açıkça yazmıyor).

## Sonuçlar / riskler
Gece incelemesi bu kuralı özellikle kontrol eder: "DM views showing server info" ([[zamanlanmis-gorevler-ve-skiller]]).
